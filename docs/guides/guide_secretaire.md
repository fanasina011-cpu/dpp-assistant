# Guide de la Secrétaire de Direction — DPP Assistant

Vous assistez le Directeur et coordonnez son agenda, ses instructions et ses dossiers.

---

## Gérer l'agenda du Directeur

1. Cliquez sur **Agenda** dans la barre latérale.
2. Pour créer un événement, cliquez sur **+ Nouvel événement**.
3. Remplissez : titre, type (Réunion, Audience, Déplacement...), dates, participants.
4. **Ajoutez le Directeur en participant** : l'événement apparaîtra dans son agenda.
5. Validez.

**Astuce :** utilisez le champ **Niveau de priorité** :
- **Direction** : priorité haute (affiché en rouge dans l'agenda).
- **Personnel** : par défaut.

En cas de conflit de créneau pour le Directeur, une modale d'avertissement apparaît. Vous pouvez **valider malgré le conflit** — le Directeur a souvent plusieurs options à la même heure.

---

## Saisir une instruction pour le Directeur

Le Directeur peut vous déléguer la saisie de ses instructions.

1. Cliquez sur **Instructions**.
2. Cliquez sur **+ Nouvelle instruction**.
3. Remplissez les champs comme d'habitude.
4. **Ne vous mettez pas comme destinataire** — sélectionnez les vrais destinataires (Chefs de service, Conseillère).
5. Validez.

**Note :** l'instruction est émise **au nom du Directeur**, pas au vôtre.

---

## Consulter tous les comptes-rendus

Vous avez une vue **globale** sur les comptes-rendus de tous les services.

1. Cliquez sur **Comptes-rendus**.
2. Vous voyez la liste complète.
3. Filtrez par **rédacteur** pour cibler une personne.
4. Filtrez par **En cours** ou **Clôturés**.

---

## Préparer une synthèse

Vous pouvez générer des synthèses pour le Directeur.

1. Cliquez sur **Synthèses**.
2. Cliquez sur **+ Générer une synthèse**.
3. Sélectionnez le type (Quotidienne, Hebdomadaire, Mensuelle) et la période.
4. Le contenu est calculé automatiquement à partir des CRQ, tâches et blocages.
5. Cliquez sur **Générer**.

Vous pouvez ensuite consulter, imprimer ou transmettre la synthèse au Directeur.

---

## Astuces

- **Les notifications** vous préviennent quand une instruction reçoit une mise à jour.
- **Votre tableau de bord** affiche les événements du jour, les blocages urgents et les demandes de réouverture CRQ.
